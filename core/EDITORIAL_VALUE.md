# UNFOLDIQ Editorial Value Transformation

## Purpose

**Research Brief is raw material. It is NOT the final script.**

**ROADMAP V5 handoff (canonical owner — this file):**
`Research Pack (factual/hybrid) or Story/Character/World context (fiction) → EDITORIAL STRATEGY (this file) → STORYTELLING`.
Editorial Strategy owns: core viewer question, core promise, chosen angle, main insight, what matters/omit, hook basis, narrative progression, payoff, uncertainty to preserve, production constraints.
**RESEARCH SUMMARY ≠ SCRIPT** — never narrate research in source order unless editorial intent requires it.

The transformation from research → script must create value beyond what a viewer could get by reading search results or Wikipedia.

---

## Beyond-Search Value Gate (Mandatory)

**Before a script is considered ready, agent MUST answer:**

> "What does the viewer receive from this video that they could NOT get by reading the top search results / Wikipedia summary in 30 seconds?"

The script must deliver at least one of these value types appropriate to the topic and mode:

| Value Type | Description |
|------------|-------------|
| `causal_explanation` | Why something happens; mechanism, not just correlation |
| `mechanism` | How something works step-by-step (physical, biological, technical) |
| `synthesis` | Integrating multiple sources into a coherent picture viewer couldn't easily assemble |
| `evidence_walkthrough` | Walking through specific evidence: "Here is the bone, here is the cut mark, here is what it means" |
| `case_example` | Concrete, detailed case that illuminates the general principle |
| `comparison` | Structured comparison across cases, time periods, methods, or theories |
| `misconception_correction` | "Commonly believed X, but evidence shows Y because..." |
| `timeline_context` | Placing events/discoveries in chronological and conceptual context |
| `expert_interpretation` | Presenting a specific scholarly interpretation with its evidence base and caveats |
| `implication` | "This discovery changes our understanding of X because..." |
| `visual_demonstration` | Showing rather than telling (animation, diagram, walkthrough) |
| `human_stakes` | Why this matters to human experience, not just abstract facts |
| `counterintuitive_insight` | "Contrary to intuition, X because Y" |
| `structured_decision_framework` | Framework for viewer to evaluate similar claims/questions |
| `practical_demonstration` | Showing how to do/apply something (technical, tutorial) |

**Not all types required per video.** Select types appropriate to topic, mode, and evidence.

---

## Research Summary Is NOT a Script (MANDATORY)

**Forbidden Pattern:**

Fact 1.
Fact 2.
Fact 3.
Researchers say X.
Researchers say Y.
Conclusion.

**If a script primarily paraphrases research in source order:**
→ `REVISE`

**Storytelling MUST reorganize information by viewer question/value, NOT source order.**

The research brief is organized by claim/evidence. The script is organized by viewer question → evidence → explanation → payoff.

---

## Example Policy — CONDITIONAL (Not Mandatory)

Examples/cases/demos are **OPTIONAL**. Do NOT force every video to include an example.

**Agent must decide:**

> "Would a concrete example materially improve:
> - comprehension?
> - credibility?
> - visualization?
> - emotional connection?
> - practical usefulness?"

**If YES and verified example exists:** Include it.

**If YES but no verified example:**
- Seek additional evidence if scope permits
- Or use clearly-labeled hypothetical scenario (`SCENARIO` type in research brief)
- Or omit example

**If NO:** Do not force an example.

**NEVER invent factual examples.**

## Domain-Aware Example Mapping

### Ancient Humans / Historical / Archaeological
Useful examples:
- Specific archaeological site (e.g., "At Zhoukoudian, Layer 10...")
- Specific artifact (e.g., "The Schöningen spears, dated to 300k years...")
- Fossil specimen (e.g., "The Turkana Boy skeleton (KNM-WT 15000)...")
- Footprint site (e.g., "Laetoli Footprints, Trail G...")
- Dated find with context

**Must explain for each:**
- What was found?
- What can it tell us?
- What can it NOT tell us?
- Why does it matter to the topic?

**Do NOT use a single reconstruction scene as "proof."**

### Technical / React / Frontend
Useful examples:
- Minimal code demo (before/after)
- Browser behavior walkthrough
- Performance trace / flame graph
- Concrete bug and fix
- Data flow diagram
- Interactive sandbox (if interactive)

### News / Current Events
Useful examples:
- Timeline of events
- Documented event with date/location
- Official statement with citation
- Key data point with source
- Comparison with prior analogous event

### Meditation / Guided
Factual examples often **not needed**. The experience/sequence itself is the value.

## Viewer Knowledge Calibration (Mandatory)

**Avoid two extremes:**

| Extreme | Problem |
|---------|---------|
| **Too shallow** | Explains obvious facts viewer could search in 5 seconds (e.g., "The Great Pyramid is in Egypt") |
| **Too expert** | Jargon, assumptions, skipped steps that lose target audience |

**Adapt depth based on:**
- Target audience (general, technical, academic, kids)
- Content mode (tutorial needs more depth; news explainer needs less)
- Platform (TikTok: hook fast, less depth; YouTube: more depth allowed)
- Duration (shorter = less depth)
- Topic complexity (narrow scope = more depth possible)

## Insight Chain (Per Major Section/Beat)

Each major section/beat SHOULD follow a value-delivering pattern:

Viewer Question / Hook
    ↓
Evidence (what was found/measured)
    ↓
Explanation / Mechanism (why/how)
    ↓
Optional Concrete Example (if improves value)
    ↓
Meaning / Implication / Payoff (why it matters)
    ↓
Next Question / Transition

**Not every scene needs all 6 elements.** But a section MUST NOT exist only to fill duration.

---

## Engagement Without Distortion (MANDATORY)

**Interesting ≠ Distortion.**

The following are FORBIDDEN to manufacture engagement:

| Forbidden | Why |
|-----------|-----|
| Exaggeration | Inflates certainty/impact beyond evidence |
| Fake suspense | "What they found next will shock you..." when outcome is known |
| Invented stakes | "If they failed, humanity would have gone extinct" (unless evidence supports) |
| False certainty | Presenting hypothesis/interpretation as established fact |
| Sensational wording | "Secret," "Hidden," "Shocking," "Never before seen" without evidence |
| Clickbait hooks | Promise not delivered in content |

**Rule:** If the most accurate version is less "dramatic" than a fabricated version → **choose the accurate version.**

Hook/storytelling MUST remain faithful to evidence and claim classes.

## "AI Reading Research" Smell Checks (Script REVISE Triggers)

Script MUST be revised if it exhibits these patterns:

| Smell | Description |
|-------|-------------|
| Generic encyclopedia cadence | Uniform rhythm, no variation in sentence structure/energy |
| Repeated "research shows / experts say" without explaining | Authority appeal without substance |
| Sequence of disconnected facts | Fact A. Fact B. Fact C. No connective tissue |
| No mechanism/causal explanation when topic demands it | "X happened" without "because Y" |
| No concrete nouns/details despite verified evidence | "Ancient tools were made" vs "Flint handaxes with bifacial flaking" |
| Every paragraph same rhythm/cadence | Monotone delivery pattern |
| No audience question/payoff structure | Information dump without question→payoff |
| Source-order narration | "Study A found X. Study B found Y. Study C found Z." |
| Unnecessary adjectives replacing insight | "Amazing discovery reveals..." instead of "Cut marks on the femur indicate..." |
| Fake rhetorical questions | "But what does this mean? [immediate answer]" without genuine tension |
| Repetition to pad duration | Repeating same point in different words |

**These are smell checks, not rigid formulas.** Agent uses editorial judgment. But presence of multiple smells = strong `REVISE` signal.

---

## Duration Expansion Discipline (STEP 10A-FIX)

Duration expansion is valid ONLY when expansion adds real editorial value
(new mechanism, evidence walkthrough, case, comparison, implication).

Reject filler patterns built to reach a duration target:

- redundant restatement of the same point;
- generic introduction inflation;
- source-order narration;
- repeated conclusion;
- irrelevant historical context;
- fake rhetorical questions;
- unsupported examples.

## Script Handoff Readiness Checklist

Before script is `READY` for Creative Direction:
- [ ] Research brief is `READY` (or `PARTIAL` with documented caveats)
- [ ] Content mode resolved and validated
- [ ] Script delivers at least one Beyond-Search value type
- [ ] Script structure follows viewer question → evidence → explanation → payoff
- [ ] No forbidden patterns (see Smell Checks)
- [ ] Claim classes respected: no `UNVERIFIED`/`HYPOTHESIS` stated as fact
- [ ] Caveats preserved where material
- [ ] Examples conditional, labeled, evidence-linked
- [ ] Engagement earned through insight, not distortion
- [ ] Viewer knowledge calibrated for target audience/mode/platform
- [ ] Each major section has clear viewer value/purpose

## Mechanical Epistemic Gate vs Editorial Judgment (STEP 08 FIX 2)

Editorial review handles subjective quality (value gate, insight chain, smell checks, calibration).

Invariants below are NOT subjective and MUST be rejected mechanically by `lib/research-quality-check.js` BEFORE Storytelling (Stage 4), not left to reviewer discretion:

```text
UNVERIFIED + CAN_STATE
UNSUPPORTED evidenceStatus + CAN_STATE
HYPOTHESIS + CAN_STATE
CONTESTED + CAN_STATE
invalid claim + handoff.readyForStorytelling = true
```

Schema-valid does not mean semantically valid. See `core/RESEARCH_QUALITY.md` Semantic Validation section.
