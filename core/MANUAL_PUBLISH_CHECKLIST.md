# UNFOLDIQ Manual Publish Checklist (STEP 09 V2)

The user uploads manually. No upload API exists in UNFOLDIQ.
Complete every item before uploading the final MP4.

- [ ] Final video path: `out/<project>-<timestamp>.mp4` exists and plays correctly
- [ ] Target platform: youtube | tiktok (one checklist per platform)
- [ ] Policy snapshot ID used for final review: recorded
- [ ] Policy verification status: `CURRENT_LIVE_VERIFIED` | `SNAPSHOT_ONLY` | `STALE` | `NOT_VERIFIED`
- [ ] If `SNAPSHOT_ONLY`/`STALE` on critical categories: publish is `PUBLISH_REVIEW_REQUIRED` — re-verify official sources first
- [ ] AI disclosure decision: `NOT_REQUIRED` | `REQUIRED` | `REVIEW_REQUIRED`
- [ ] If disclosure `REQUIRED`: platform label/disclosure action completed (YouTube "how this content was made" / TikTok AI-generated label)
- [ ] Rights: no unresolved `REVIEW_REQUIRED`/`BLOCKED` issues; licenses/permissions filed
- [ ] Attribution requirements: all required credits present (CC, stock, sources)
- [ ] Likeness/voice warnings: real-person depictions cleared or disclosed; synthetic endorsements removed
- [ ] Monetization/ad-suitability warnings: reviewed; no monetization guaranteed
- [ ] Reconstruction note: every realistic reconstruction labeled; none presented as evidence
- [ ] Required user actions from policy review handoff: all completed
- [ ] QA report: all checks PASS; render evidence captured
