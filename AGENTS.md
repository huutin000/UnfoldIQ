# AGENTS.md — UnfoldIQ Agent Instructions

## Video Production Agent Governance

Before performing any task that can directly or indirectly affect video/content
output, read:

`docs/youtube/governance/VIDEO_PRODUCTION_AGENT_CONTEXT_GATE.md`

If the gate classifies the task as `VIDEO_AFFECTING_TASK: YES`, follow its
required preflight and canonical YouTube governance sources before execution.

Do not bypass this rule by modifying project state, SQLite, render manifests,
generation jobs, or production artifacts directly.
