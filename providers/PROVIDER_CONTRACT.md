# UNFOLDIQ Generic Provider Contract

## Minimum Input Contract

A provider request MUST include the following fields when relevant to the capability:

| Field | Type | Description |
|-------|------|-------------|
| `requestId` | string | Unique identifier for this provider call (e.g., UUID) |
| `capability` | string | One of: `image`, `video`, `tts`, `stt`, `music`, `sfx` |
| `sceneId` | string | Scene identifier from scene plan |
| `creativeDirection` | object | Reference to global creative direction (tone, mood, pacing, etc.) |
| `visualBibleConstraints` | object | Relevant Visual Bible fields (style, palette, character, environment, negative constraints) |
| `platformConstraints` | object | Platform profile constraints (aspect ratio, safe zones, duration, resolution) |
| `promptOrText` | string | Generation prompt (image/video) or text to synthesize (TTS) |
| `inputAssets` | array | Paths to input assets for edit/transform operations |
| `outputRequirements` | object | Required output specs: dimensions, format, duration, fps, sample rate, etc. |
| `rightsContext` | object | Intended use, license requirements, commercial flag |
| `attempt` | integer | Retry attempt number (1 for first try) |

**Not all fields are required for every capability.** Only fields relevant to the specific capability and operation must be provided.

## Minimum Output Contract

A provider result MUST include:

| Field | Type | Description |
|-------|------|-------------|
| `status` | string | `READY` \| `FAILED` \| `BLOCKED` \| `NOT_AVAILABLE` \| `HANDOFF_REQUIRED` \| `AWAITING_USER_APPROVAL` |
| `providerId` | string | Logical provider ID used (e.g., `openai-image`, `agent-native`, `existing`) |
| `capability` | string | Capability that was requested |
| `artifactPath` | string | **Required if `READY`**: Relative path to generated/saved artifact in project |
| `mimeType` | string | MIME type of artifact if known (e.g., `image/png`, `audio/mpeg`, `video/mp4`) |
| `metadata` | object | Additional metadata: dimensions, duration, sample rate, frame count, etc. |
| `sourceType` | string | `existing` \| `generated` \| `local-library` |
| `generationDate` | string | ISO 8601 timestamp (required if `sourceType` is `generated`) |
| `modelOrVersion` | string | Model name/version used if known/applicable |
| `requestId` | string | Echo of input requestId |
| `sceneId` | string | Echo of input sceneId |
| `provenanceNote` | string | Brief note on origin: generated by which provider, edited from which source, etc. |
| `rightsStatus` | string | `VERIFIED` \| `UNVERIFIED` \| `UNKNOWN` \| `NOT_APPLICABLE` |
| `errorCode` | string | **Required if not `READY`**: Machine-readable error code |
| `errorSummary` | string | **Required if not `READY`**: Human-readable error description |

**No chain-of-thought, internal reasoning, or raw API responses** in provider result. Only the contract fields above.

## Retry Principles

- **No infinite retries**: Retry attempts are bounded.
- **Retry only transient/technical failures**: Network timeout, temporary service unavailable, rate limit (with backoff).
- **Do NOT retry on**: Policy/validation errors, content filter rejections, invalid input, missing secrets, fundamental capability mismatch.
- **Retry limit**: Specific limit to be implemented in later step. Step 06 defines principle only.
- **Fallback on exhaustion**: If retries exhausted and no success, try next provider in `preferredOrder` or apply fallback rules per `providers/INDEX.md`.

## Status Code Semantics

| Status | Meaning |
|--------|---------|
| `READY` | Artifact successfully generated/saved and available at `artifactPath` |
| `FAILED` | Provider call failed (technical error, will not succeed on retry with same input) |
| `BLOCKED` | Cannot proceed — missing required capability, secret, or valid fallback |
| `NOT_AVAILABLE` | Provider not configured or not callable in current environment |
| `HANDOFF_REQUIRED` | Manual/external provider needed; persistent handoff JSON written with return instructions |
| `AWAITING_USER_APPROVAL` | Prepared but needs user approval for a quota/credit-consuming or external action |

## Cost Classes

`ZERO_LOCAL` (no per-request provider charge — not zero electricity/hardware/time) · `INCLUDED_SUBSCRIPTION` · `FREE_TIER` · `PAID` · `UNKNOWN`.

Project default (`providers/CONFIG.yaml → costPolicy`): `preferZeroMarginalCost: true`, `allowPaidCloud: false`. Paid providers are never auto-called without explicit enable.
